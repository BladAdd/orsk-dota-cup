# Кубок Орска по Dota 2

Официальный сайт открытого любительского турнира по Dota 2 (Орск, Оренбургская область).
Призовой фонд 15 000 ₽ предоставлен Орским городским отделением КПРФ.

## Что внутри

- **Публичный сайт**: главная, регистрация команд, список команд и составов, живая сетка single elimination,
  расписание, регламент, призовые, новости с обсуждением, спонсоры, политика персональных данных.
- **Админка оргкомитета** (`/admin`): заявки и допуск команд, генерация и правка сетки, внесение результатов
  с автоматическим продвижением победителей, новости, премодерация комментариев с баном и жалобами, настройки турнира.
- **База**: Supabase (Postgres + Auth + Storage + Row Level Security). Схема и политики — в `supabase/migrations/`.

## Технологии

Чистый HTML + CSS + ES-модули без сборки (деплой = `git push`). Клиент Supabase завендорен в `assets/vendor/`,
чтобы сайт не зависел от внешних CDN.

## Быстрый старт

1. Подключите базу по инструкции [`supabase/SETUP.md`](supabase/SETUP.md).
2. Вставьте ключи в `assets/js/config.js`.
3. Локально: `python -m http.server 8080` и откройте http://localhost:8080.
4. Деплой: запушьте репозиторий на GitHub и включите Pages (Settings → Pages → Branch `main`, корень).
   Все пути в разметке относительные, поэтому сайт корректно живёт в подпапке `/<имя-репозитория>/`.

## Структура

```
assets/css        дизайн-система (base / site / admin)
assets/js         клиент: db, auth, ui, chrome, comments, bracket-engine
assets/js/pages   логика публичных страниц
assets/js/admin   логика админки
supabase/         миграции и инструкция по подключению
tools/            служебные скрипты (генерация OG-картинки)
```

## Принципы

- Комментарии — только реальные, с премодерацией; накрутки и фейковых отзывов нет и не будет.
- Персональные данные (ФИО, телефоны, e-mail) не публикуются: наружу через SQL-представления
  (`v_teams_public`, `v_comments_public` и др.) отдаются только никнеймы, роли и ссылки на Steam.
- Dota 2 — товарный знак Valve Corporation; сайт не аффилирован с Valve.
